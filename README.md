# Olá, sou Phelipe Bessa!

Sou formado em Análise e Desenvolvimento de Sistemas e estou direcionando minha carreira para o desenvolvimento backend com Java.

Tenho interesse em engenharia de software, arquitetura de sistemas e desenvolvimento de aplicações que resolvam problemas reais.

Atualmente, estou aprofundando meus conhecimentos em Java, Spring Boot, APIs REST, bancos de dados relacionais e testes automatizados, colocando esses conceitos em prática nos meus projetos.

### Tecnologias com as quais estou trabalhando

- **Backend:** Java, Spring Boot, Spring Data JPA e Hibernate
- **Banco de dados:** PostgreSQL e SQL
- **Testes:** JUnit 5 e Mockito
- **Ferramentas:** Git, GitHub, Docker, Maven e IntelliJ IDEA
- **Outros conhecimentos:** Python, React, React Native, JavaScript, Angular e Vue.js

### Projeto em desenvolvimento

**PerfumeHub** — Sistema backend para gerenciamento de produtos, categorias e estoque de uma perfumaria.

O projeto está sendo desenvolvido com Java e Spring Boot, utilizando PostgreSQL, Flyway e testes automatizados.

### Objetivo profissional

Busco minha primeira oportunidade como desenvolvedor backend Java, onde possa contribuir com projetos reais e continuar evoluindo tecnicamente.
